BLOOP — соцсеть и мессенджер. Сервер для друзей (v4.7)

1. Установи Node.js с nodejs.org (нужна версия 22.5+).
2. Запусти run-server.bat (Windows) или: npm ci && node server.js
3. Открой http://localhost:3000 — и работай: лента, клипы, чаты, звонки.
4. Друзья в той же Wi-Fi: в APK — Настройки → «Сервер для друзей» → введи
   адрес, который напечатает сервер (http://192.168.x.x:3000).
5. Для ВСЕХ пользователей интернета: разверни сервер на Render.com за 5
   минут (render.yaml в репозитории — README «Публичный сервер за 5 минут»),
   впиши адрес в servers.json — и каждый скачанный APK найдёт сервер сам.
   Один файл на всех, все видят друг друга, масштаб до миллиона.

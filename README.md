# BLOOP — веб-мессенджер

BLOOP — это веб-мессенджер в реальном времени: личные и групповые чаты,
мгновенная доставка сообщений по WebSocket, онлайн-статусы, индикатор
«печатает…» и отправка изображений. Всё в одном репозитории, минимум
зависимостей (только `express` и `socket.io`; база данных — встроенный
в Node.js SQLite, пароли — `scrypt`, сессии — подписанные HMAC-токены).

## Возможности

- Регистрация и вход (логин + пароль, пароли хэшируются scrypt)
- Личные чаты 1-на-1 и групповые чаты (создание с выбором участников)
- Сообщения в реальном времени (Socket.IO), автопереподключение
- Онлайн-статусы и индикатор набора текста
- Отправка изображений до 8 МБ (PNG/JPEG/GIF/WebP)
- Счётчик непрочитанных, разделители дней, адаптивный интерфейс
  (телефон/планшет/десктоп), тёмная тема

## Запуск

Требуется Node.js 22.5+ (используется встроенный модуль `node:sqlite`).

```bash
npm install
npm start          # сервер на http://localhost:3000
```

Переменные окружения (все необязательные):

| Переменная       | По умолчанию | Что делает                         |
| ---------------- | ------------ | ---------------------------------- |
| `PORT`           | `3000`       | порт HTTP-сервера                  |
| `BLOOP_DATA_DIR` | `./data`     | папка для базы, секрета и загрузок |
| `BLOOP_SECRET`   | генерируется | секрет для подписи токенов         |

Данные хранятся в `data/bloop.db` (SQLite), загруженные изображения —
в `data/uploads/`.

## Проверка (smoke-тест)

```bash
npm install        # вместе с dev-зависимостью socket.io-client
npm run smoke      # поднимает сервер на :3107 и прогоняет сценарий
```

Тест регистрирует двух пользователей, открывает личный чат, проверяет
дедупликацию чатов, доставку сообщения через WebSocket, присутствие
(online), непрочитанные, групповой чат и загрузку изображения.

## Docker

```bash
docker build -t bloop .
docker run -p 3000:3000 -v bloop-data:/app/data bloop
```

## Структура

```
server.js          — Express + Socket.IO: REST API, realtime, загрузка картинок
src/db.js          — SQLite-схема и запросы (node:sqlite)
src/auth.js        — scrypt-хэши паролей, HMAC-токены сессий
public/            — фронтенд (vanilla JS, без сборки)
  index.html       — каркас: экран входа, список чатов, чат, модалка группы
  style.css        — тёмная адаптивная тема
  app.js           — логика клиента
test/smoke-test.mjs — интеграционный тест API + WebSocket
```

## API (кратко)

| Метод | Путь                        | Описание                        |
| ----- | --------------------------- | ------------------------------- |
| POST  | `/api/register`             | регистрация, возвращает токен   |
| POST  | `/api/login`                | вход, возвращает токен          |
| GET   | `/api/me`                   | текущий пользователь            |
| GET   | `/api/users`                | список пользователей (+online)  |
| GET   | `/api/chats`                | мои чаты с последним сообщением |
| POST  | `/api/chats`                | создать чат (`direct`/`group`)  |
| GET   | `/api/chats/:id/messages`   | история (пагинация `before`)    |
| POST  | `/api/chats/:id/messages`   | отправить текст/изображение     |
| POST  | `/api/chats/:id/read`       | отметить прочитанным            |

WebSocket (Socket.IO): события `message`, `typing`, `presence`,
`presence:list`, `chat:new`. Авторизация сокета — токен в
`handshake.auth.token`.

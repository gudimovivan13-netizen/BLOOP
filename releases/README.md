## BLOOP-4.2.exe — Windows, приложение с нейросетью

exe — это полноценное десктоп-приложение (обёртка Electron):
двойной клик открывает **собственное окно BLOOP** с иконкой в панели задач,
без вкладки браузера и без консоли. Внутри окна работает тот же мессенджер,
что и в веб-версии (лента, клипы, чаты, звонки, боты), плюс встроенная
нейросеть **BLOOP AI** — идеи постов, хэштеги, подписи, Вирусометр и
«напиши в моём стиле». Нейросеть локальная: внешних API нет.

1. Скачайте `BLOOP-4.2.exe` и положите в любую папку.
2. Запустите двойным кликом — откроется окно приложения.
3. Данные (аккаунты, чаты, файлы) лежат в папке `data` рядом с exe: если вы
   пользовались старым exe 4.0 — новые версии автоматически подхватят
   существующую базу, ничего переносить не нужно.
4. Повторный запуск, пока BLOOP уже открыт, просто поднимает существующее
   окно (второй экземпляр не создаётся).

Порт выбирается автоматически: 3000, если он свободен, иначе любой
свободный — конфликтов с другими программами не будет.

Особенности сборки (exe не подписан сертификатом):

- SmartScreen при первом запуске покажет предупреждение — нажмите
  «Подробнее → Выполнить в любом случае». Проверить целостность файла
  можно по сумме SHA256 выше.
- Иконка в окне и на панели задач — BLOOP; иконка самого файла в Проводнике
  пока стандартная (для вшивания иконки в exe нужен подписанный сборщик —
  это можно добавить позже).

## BLOOP-4.2.apk — Android

1. Скачайте `BLOOP-4.2.apk` на телефон и откройте его.
2. Разрешите установку из этого источника (система спросит один раз).
3. Приложение работает полностью офлайн: «сервер» — на самом устройстве
   (localStorage + IndexedDB), все фичи доступны без сети — включая
   нейросеть **BLOOP AI**: идеи постов, хэштеги, Вирусометр и «напиши
   в моём стиле» считаются прямо на телефоне, без сети и без внешних API.

Для режима с общим сервером и звонками между устройствами используйте
веб-версию или десктоп-приложение: запустите сервер из корня репозитория
(`node server.js`) и откройте его адрес в браузере телефона.

## Что нового

- **4.2** — **BLOOP AI**: своя нейросеть (MLP-классификатор намерений +
  генераторы на данных соцсети) прямо в ассистенте — на сервере, в exe и
  в APK (офлайн, на устройстве), без внешних API. Новая аватарка ассистента
- **4.1 (exe)** — exe стал настоящим приложением: своё окно Electron вместо
  вкладки браузера, иконка в панели задач, авто-выбор порта, защита от
  второго экземпляра, перенос данных из 4.0.
- **4.0** — аудио- и видеозвонки 1-на-1 (WebRTC), поиск по сообщениям,
  правка/удаление/пересылка, закреплённые сообщения и чаты, управление
  группами, эмодзи-панель, черновики, уведомления. Полный список — в
  [README](../README.md) корня.

## Обновление этой папки

Новые версии добавляются сюда же с номером в имени файла
(`BLOOP-4.3.exe`, `BLOOP-4.3.apk`), старые остаются для истории.

Сборка exe: `bash scripts/build_exe.sh` (бандл esbuild + обёртка Electron
из `app/desktop/`, сборка `electron-builder --win portable`).
Сборка APK: `cd app/android && ./gradlew assembleDebug` — подробности в
[README](../README.md) корня репозитория.

В этой папке лежат собранные и проверенные файлы последней версии — можно
скачать и пользоваться без сборки из исходников.

| Файл | Платформа | Размер | Что это |
|------|-----------|--------|---------|
| [BLOOP-4.0.exe](BLOOP-4.0.exe) | Windows 10/11 (64-bit) | 92 МБ | Сервер + веб-клиент в одном файле (Node SEA) |
| [BLOOP-4.0.apk](BLOOP-4.0.apk) | Android 7.0+ | 4.5 МБ | Автономное приложение (versionCode 11) |

## BLOOP-4.0.exe — Windows

1. Скачайте `BLOOP-4.0.exe` и положите в любую папку.
2. Запустите двойным кликом: рядом появится папка `data` (база SQLite,
   загруженные файлы) и откроется браузер на `http://localhost:3000`.
3. Регистрируйтесь и пользуйтесь — сервер работает локально на вашей машине.

Порт меняется переменной окружения `PORT`, например:

```
set PORT=8080 && BLOOP-4.0.exe
```

Файл собран как однофайловое приложение Node.js (SEA) и не подписан
сертификатом: SmartScreen при первом запуске покажет предупреждение —
нажмите «Подробнее → Выполнить в любом случае». Это нормально для
личных сборок; сумма выше позволяет проверить, что файл не изменён.

## BLOOP-4.0.apk — Android

1. Скачайте `BLOOP-4.0.apk` на телефон и откройте его.
2. Разрешите установку из этого источника (система спросит один раз).
3. Приложение работает полностью офлайн: «сервер» — на самом устройстве
   (localStorage + IndexedDB), все фичи доступны без сети.

Для режима с общим сервером и звонками между устройствами используйте
веб-версию: поднимите сервер из корня репозитория (`node server.js`) и
откройте его адрес в браузере телефона — права камеры и микрофона для
звонков уже запрошены при установке.

## Что нового в 4.0

Аудиозвонки и видеозвонки 1-на-1 (WebRTC, сигнализация через ваш сервер),
поиск по сообщениям, правка/удаление/пересылка сообщений, закреплённые
сообщения и чаты, управление группами, эмодзи-панель, черновики, звуковые
и браузерные уведомления. Полный список — в [README](../README.md) корня.

## Обновление этой папки

Новые версии добавляются сюда же с номером в имени файла
(`BLOOP-4.1.exe`, `BLOOP-4.1.apk`), старые остаются для истории.
Сборка: `bash scripts/sea_build.sh` для exe и
`cd app/android && ./gradlew assembleDebug` для APK — подробности в
[README](../README.md) корня репозитория.

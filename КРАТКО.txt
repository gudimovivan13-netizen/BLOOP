BLOOP сервер для друзей

1. Установи Node.js с nodejs.org (если нет).
2. Запусти run-server.bat (Windows) или: npm ci && node server.js
3. Скажи другу адрес, который напечатает сервер.
4. Друг: BLOOP → Настройки → «Сервер для друзей» → введи адрес.
5. Вы видите друг друга: лента, «Люди», чаты, звонки.
